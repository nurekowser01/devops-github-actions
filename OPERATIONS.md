# Pipeline Operations

## Manual Overrides
In the event of a catastrophic pipeline failure, administrators can bypass the CI/CD pipeline by directly accessing the target host and executing:
```bash
docker stop app-container
docker run -d --name app-container -p 3000:3000 ghcr.io/nurekowser01/devops-github-actions:sha-<PREVIOUS_KNOWN_GOOD_SHA>
```
Because the pipeline uses immutable tags, rolling back outside of GitHub Actions is deterministic.

## Monitoring the SBOM
The SBOM generated by Syft is uploaded as an artifact to every successful GitHub Actions run. Operators can download the `sbom.spdx.json` file directly from the Actions UI to audit licenses and dependency versions.
